Проект Social media API представляет собой социальную сеть, 
в которой пользователи могут общаться и следить за активностью друг друга.

Основная механика процесса:
пользователь отправляет заявку в друзья
→ становится подписчиком
→ второй пользователь принимает заявку
→ создаётся дружба
→ оба пользователя становятся подписчиками друг друга
→ система отправляет уведомления

Social Media API включает в себя следующие технологии и возможности:

REST API и OpenAPI-контракт;
PostgreSQL и управляемые миграции;
Spring Data JPA и транзакции;
аутентификацию через Keycloak;
модульные, интеграционные и сценарные тесты;
структурные логи в Loki;
метрики для Prometheus и Grafana;
трассы OpenTelemetry в Jaeger;
асинхронные уведомления;
воспроизводимое развертывание через Docker Compose.
